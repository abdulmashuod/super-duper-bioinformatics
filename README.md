# Bioinformatics Fundamentals Learning - 10 Day Challenge

A structured 10-day learning journey through the fundamental concepts of bioinformatics.

## 📋 Overview

This repository tracks daily learning progress on core bioinformatics topics:
- DNA/RNA sequences & structure
- Sequence alignment
- Protein structure & function
- Gene finding & annotation
- Phylogenetics
- NGS analysis
- And more...

## 📅 10-Day Curriculum

- **Day 1**: Introduction to Bioinformatics
- **Day 2**: DNA/RNA Sequences & Structure
- **Day 3**: Sequence Alignment Basics
- **Day 4**: Multiple Sequence Alignment
- **Day 5**: Protein Structure & Function
- **Day 6**: Gene Finding & Annotation
- **Day 7**: Phylogenetic Analysis
- **Day 8**: Bioinformatics Databases
- **Day 9**: Next-Generation Sequencing (NGS)
- **Day 10**: Practical Tools & Pipelines

## 📝 How to Use

1. **Daily Reading**: Read the recommended article for each day
2. **Take Notes**: Document key learnings in `notes.md`
3. **Extract Concepts**: List important concepts in `key-concepts.md`
4. **Track Resources**: Add links and references in `resources.md`
5. **Update Progress**: Mark completion in `progress.md`
6. **Commit**: Push your changes to GitHub daily

## 🚀 Getting Started

```bash
# Clone or download this repository
# Navigate to the project
cd bioinformatics-learning-2026

# For each day:
cd Day-01-Introduction
# Edit notes.md, key-concepts.md, resources.md
# Save and commit changes

git add .
git commit -m "Day 1: Introduction to Bioinformatics completed"
git push origin main
```
